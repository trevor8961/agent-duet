# agent-duet

> 让 agent 的思考与行动，第一次可以被看见。

![会话视图](docs/images/session.png)

## 你大概也有过这些时刻

**开了一个很长的会话，回头却找不到了。**
它是在哪个目录里开的？聊到哪儿了？重启之后翻遍历史也拼不回来——
因为「时间 + 目录 + 话题」这些信息，从来没有被结构化地记录过。

**盯着终端里滚滚而下的瀑布流，只想问一句：它在干嘛？**
一次回复里，agent 对你的正式回答、它自己的喃喃自语、跑的命令、读的文件……
全部搅在一起往下冲。你找不到重点，也很难回顾它到底想了什么、做了什么。

**它在动手，但你完全没被问到。**
auto 模式直接改文件、manual 模式步步确认、plan 模式先出方案——
这些截然不同的行为，在终端里却长得一模一样，你无从感知差异。

**换个 agent 就像换个世界。**
claude code、pi……各说各话，没有一个地方能把它们统一起来。

如果你点头了，那 agent-duet 就是为你做的。

## agent-duet 把这一切变成了「看得见」的界面

它把 agent 的输出拆成**三类内容**，各归其位：

- 💬 **正式回复** —— agent 对你的答复（纸卡呈现，折叠态只留标题目录）
- 💭 **思考过程** —— 它的推理与嘀咕（收进可折叠的「幕后块」，想看才展开）
- 🔧 **工具调用** —— 每一次操作（终端样式，输入输出清清楚楚）

再给每一场会话**留档**：在哪个目录、聊了什么、跑了多少轮、动过哪些文件——
下次想找，一秒就够。

## 特色

| 能力 | 说明 |
|---|---|
| 🔍 会话档案 | 按话题搜索、按目录分组，长会话不再丢失 |
| 🎼 分层呈现 | 回复 / 思考 / 工具 分层展示，告别瀑布流 |
| 🔐 事中授权 | 引导模式下每个写操作弹授权卡，批准/拒绝/超时**永久留痕** |
| 📊 节目单 | 每一轮意图 + 思考数 + 工具数 + 耗时，一目了然 |
| 🌿 Git 感知 | 侧栏实时显示分支、变更文件，agent 改了什么立刻可见 |
| 🧩 多 agent 就绪 | profile 体系，接新 agent 只加一条配置 |

## 30 秒跑起来

```bash
# macOS / Linux / WSL
./scripts/start.sh

# Windows (PowerShell)
.\scripts\start.ps1
```

首次运行自动装依赖，之后一键起前后端、自动打开浏览器。
**前置**：Python 3.12+（uv）、Node 18+、claude code 已安装可用。

详见 [快速上手](docs/getting-started.md)。

## 界面一览

![首页](docs/images/home.png)

三栏布局：**左**会话列表，**中**对话本体，**右**会话上下文（模式切换 / Git 状态 / 节目单）。

## 为什么叫 agent-duet

名字来自「二分心智」（Bicameral Mind）——远古心智一室发声、一室执行。
今天的 agent 也处于这个阶段：一边在跟你对话，一边在心里盘算。
agent-duet 做的，就是把这「对话」和「盘算」分开，让两样都能被看清。

## 我们想走得更远

结构化会话数据的终极消费者，不止是用户，还有 agent 自己。
通过离线「冥想」复盘自己的思考链与踩坑记录，agent 可以自己蒸馏并维护
工作规范——从被约束，走向自我约束。
