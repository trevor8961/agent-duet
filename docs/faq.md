# FAQ

## 使用

**Q: 换模型/供应商后，能继续刚才的话题吗？**
能。会话绑定的是 agent 自己的 session id，模型是每次调用时的配置，两者解耦。
切换 profile 的模型后，下一轮会自动 resume 带着上下文续聊。数据层还会记录
每轮实际用的模型（`turns.model`），跨模型对话史完整可审计。

**Q: 关掉页面，agent 还会继续干活吗？**
会。任务跑在后端进程的后台任务里，浏览器只是观察窗。关页面不影响执行。
但**后端进程不能关**——后端重启会导致任务中断（重启后自动标为失败，可重试）。

**Q: 中途打开页面能看到正在进行的任务吗？**
能。打开一个 running 状态的会话会自动续上实时流，并回放你离开期间产生的事件。

**Q: 权限被拒了怎么继续？**
被拒轮下方有「🔓 授权并继续」——点它本轮会以「自主」权限重新执行，
会话模式不变。被拒的原因（批准/拒绝/超时）会永久记录在时间线上。

## 常见问题

**Q: 中文输入法打字时回车会误发送？**
不会。发送是 ⌘/Ctrl+Enter，普通回车是换行，输入法选词的回车不会触发发送。

**Q: 切换会话后内容没变？**
刷新页面即可（`location.hash` 路由 + 组件重挂载，个别热更新场景需完整刷新）。

**Q: 状态条显示"工作中"但计时不走？**
这是历史版本的 SSE 假死 bug（已修复）。若仍复现，刷新页面重进即可接上实时流。

**Q: 深色主题下回复内容看不清？**
纸卡是"米色纸"设计，深色主题下纸卡文字用墨色、不随主题变。若仍有看不清的
元素，是漏网的样式，请反馈。

## 架构

**Q: 数据存在哪？**
`data/` 目录：`agent-duet.db`（SQLite，可直接用 sqlite3 打开）+ `data/raw/`
（每轮对话的原始事件流留档，可重放）。

**Q: 支持哪些 agent？**
目前 claude code。设计上通过 profile 表（`agents`）扩展——接新 agent =
加一条 profile + 一个调用适配器，前端按能力声明渲染。

**Q: 为什么不支持导入已有的 claude session？**
各家 session 是内部格式、随版本变化，解析是无底洞。边界定为"从用 agent-duet
起，数据才结构化"。
