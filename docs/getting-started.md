# 快速上手

> 从零到第一次完整对话。预计 10 分钟。

## 前置条件

- **Python 3.12+** 和 [uv](https://docs.astral.sh/uv/)（包管理）
- **Node 18+**（前端）
- **claude code 已安装并可用**：终端里 `claude` 能正常跑（agent-duet 目前以 claude code 为第一个目标 agent）

验证：

```bash
uv --version      # 应有输出
node --version    # 应有输出
claude --version  # 应有输出
```

## 启动

**一键脚本（推荐）**：

```bash
./scripts/start.sh      # macOS / Linux / WSL
# 或 Windows PowerShell：
.\scripts\start.ps1
```

首次运行自动装依赖，之后一键起前后端并打开浏览器。
停止：`./scripts/stop.sh` / `.\scripts\stop.ps1`。

**手动启动**（可选）：

```bash
cd agent-duet

# 后端（端口 8300）
cd backend && uv sync && uv run uvicorn app.main:app --port 8300

# 前端（端口 5173，另开一个终端）
cd ../frontend && npm install && npm run dev
```

浏览器打开 **http://localhost:5173**。

> 后端首次启动会自动建库（`data/agent-duet.db`）并写入一个默认的
> claude code profile（命令 `claude`，模型留空 = 用 claude 自身当前配置）。

## 第一次对话

1. 点左下角「＋ 新会话」，填：
   - **话题**：一句话描述，用于以后检索（如"修复登录超时"）
   - **工作目录**：agent 干活的目录（建议一个 git 仓库）
   - **Agent**：目前只有 claude-code
   - **模式**：见下文
2. 在输入框打字，**⌘/Ctrl + Enter** 发送（Enter 是换行）
3. agent 开始工作：中间栏实时看到它的**幕后块**（思考过程 + 工具调用）、右侧**节目单**逐轮更新
4. 完成：最终回复以**纸卡**呈现（折叠态是标题目录，展开是全文）

## 四种模式

| 模式 | 含义 | 权限行为 |
|---|---|---|
| 只读 | 只许看，不许动 | 一律拒绝写操作 |
| 计划 | 先出方案不动手 | plan 语义 |
| 引导 | 逐步确认 | **每个写操作弹授权卡，等你批准** |
| 自主 | 放手干 | 不弹，直接执行 |

模式在**右侧「模式」块**随时可切（下一轮生效），也可以在新建会话时选。

## 事中授权

在「引导」模式下，agent 遇到需要授权的操作（写文件、跑命令）时会**暂停**，
中间栏底部弹出授权卡：

```
🔐 需要授权         300s
工具：Write
{ "file_path": "..." }
[拒绝]  [批准]
```

- **批准** → agent 继续
- **拒绝** → 该操作被拒，agent 换方法或停下
- **超时**（300 秒无响应）→ 自动拒绝

每一笔授权（批准/拒绝/超时）都会**永久记录**，并作为徽章标在对应的工具卡上，
时间线上清晰可见。

## 界面速览

```
┌──────────────────────────────────────────────────────┐
│ 🎼 agent-duet  ⑂ 仓库地址            🖥 主题 🌐 语言  │  ← 顶栏
├───────────┬──────────────────────────┬───────────────┤
│ 搜索会话   │  会话对话区（分层呈现）      │ 模式（可切）    │
│ 最近       │   · 你的提问（右）         │ 基本信息       │
│ 按目录     │   · 幕后块（思考+工具 折叠） │ Git 状态      │
│           │   · 回复纸卡（标题目录）     │ 请求（节目单）  │
│           │                          │               │
│  ＋新会话  │  [输入框 ⌘/Enter 发送]      │               │
└───────────┴──────────────────────────┴───────────────┘
```

- **左侧**：会话列表（按标题搜索、按目录分组、点击切换、高亮当前）
- **中间**：对话本体——你的提问（右）、幕后过程（折叠灰块：思考+工具）、正式回复（纸卡）
- **右侧**：会话上下文——模式切换、基本信息、Git 分支/变更、节目单（每轮意图+思考/工具数+耗时）

## 已知限制

- 目前只支持 **claude code** 一个 agent（profile 体系已为多 agent 留好扩展位）
- **单用户本地**工具，无云端、无多设备同步
- **不导入历史 session**——只有用 agent-duet 发起的会话才会被结构化记录
- 关页面 agent 会继续跑（任务在后端进程里），但**别关后端**；后端重启后未完成的任务会标记失败，可重试
